# 🗺️ RepoMapper

RepoMapper is an interactive full-stack codebase visualization tool that parses repositories and renders them into an interactive dependency graph, helping developers explore file structures and relationships at a glance.

---

## 🚀 Tech Stack

* **Frontend:** React, Vite, Cytoscape.js, Custom CSS
* **Backend:** Python, FastAPI, Uvicorn, Pydantic
* **Analysis & Parsing:** Python Git & Tree-sitter / NetworkX graph processing workflows
